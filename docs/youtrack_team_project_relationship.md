# YouTrack: العلاقة بين الفرق والمشاريع

> مرجع بحثي مبني على التوثيق الرسمي لـ JetBrains YouTrack

## المفاهيم الأساسية

في YouTrack يوجد مفهومان مختلفان لإدارة الأشخاص والصلاحيات:

### 1. فريق المشروع (Project Team)

- كل مشروع لديه **فريق مشروع واحد** (Project Team) خاص به.
- فريق المشروع مرتبط بمشروع **واحد فقط**.
- عند إضافة مستخدمين أو مجموعات لفريق المشروع، الأدوار (Roles) تُطبق **فقط** ضمن سياق هذا المشروع.
- يُدار من خلال: `Project → Settings → People`.

### 2. المجموعات (Groups)

- المجموعات هي كيانات **عامة (Global)** تعمل على مستوى النظام بالكامل.
- **المجموعة الواحدة يمكن إضافتها لعدة مشاريع** مع أدوار مختلفة في كل مشروع.
- تحديث عضوية المجموعة (إضافة/حذف مستخدم) ينعكس تلقائيًا على جميع المشاريع المرتبطة بها.
- تُدار من خلال: `Administration → Access Management → Groups`.

## جدول المقارنة

| المفهوم            | النطاق           | العلاقة بالمشاريع                  | الاستخدام الموصى                          |
| ------------------ | ---------------- | ---------------------------------- | ----------------------------------------- |
| **Project Team**   | مشروع واحد فقط  | 1 مشروع ← 1 فريق مشروع            | صلاحيات فريدة لمشروع محدد                 |
| **Group (فريق)**   | عام (Global)     | 1 مجموعة ← عدة مشاريع             | إدارة صلاحيات متسقة عبر مشاريع متعددة     |

## النتيجة

> **الفريق (Group) الواحد يمتلك صلاحية على أكثر من مشروع** — وليس العكس.

- المشروع لا يمتلك "عدة فرق" بالمعنى الحرفي.
- المشروع لديه **فريق مشروع واحد** (Project Team) يمكن أن يحتوي على عدة **مجموعات (Groups)** وعدة مستخدمين فرديين.
- كل مجموعة قد تكون مشتركة في مشاريع أخرى بأدوار مختلفة.

## النموذج المنطقي

```
Organization
  └── Groups (Teams) ← كيان عام على مستوى المؤسسة
        └── Members (Users)

Project
  └── Project Team ← فريق المشروع (واحد لكل مشروع)
        ├── Group A  → role: Developer
        ├── Group B  → role: Viewer
        └── User X   → role: Project Admin
```

### العلاقة: Many-to-Many

- الفريق (Group) الواحد يمكن ربطه بعدة مشاريع.
- المشروع الواحد يمكن أن يضم عدة فرق (Groups) بأدوار مختلفة.

## الأدوار والصلاحيات (Roles & Permissions)

- الصلاحيات في YouTrack تُحدد عبر **الأدوار (Roles)**.
- الأدوار تعمل كحاويات لمجموعة من الصلاحيات.
- تُعيّن الأدوار للمستخدمين أو المجموعات **على مستوى المشروع**.
- المستخدمون يرثون الأدوار بناءً على عضويتهم في فريق المشروع أو المجموعات.

## ميزات إضافية

### لوحات Agile عبر مشاريع متعددة

- يمكن إنشاء **Agile Board واحد** وربطه بعدة مشاريع.
- يتيح للفريق تتبع المهام من مشاريع مختلفة في مكان واحد.

### إعدادات الرؤية (Visibility)

- حتى لو كان المستخدم لديه صلاحية على المشروع، يمكن تقييد رؤيته لـ issues أو comments أو attachments محددة.
- يمكن تخصيص الرؤية للفريق أو مجموعات محددة.

## التطبيق على قاعدة البيانات الحالية

بناءً على هذا البحث، الهيكل الحالي في `init_database.sql`:

```sql
-- فريق المشروع (Project Team) - واحد لكل مشروع
CREATE TABLE IF NOT EXISTS project_teams (
    id VARCHAR(20) PRIMARY KEY,
    name VARCHAR(255),
    project_id VARCHAR(20),        -- مرتبط بمشروع واحد
    ...
);

-- المشروع يشير لفريق مشروع واحد
CREATE TABLE IF NOT EXISTS projects (
    ...
    team_id VARCHAR(20) REFERENCES project_teams(id),
    ...
);
```

هذا التصميم **صحيح ومتوافق** مع نموذج YouTrack الرسمي حيث:

- كل مشروع لديه `team_id` واحد (فريق مشروع واحد).
- فريق المشروع (`project_teams`) مرتبط بـ `project_id` واحد.
